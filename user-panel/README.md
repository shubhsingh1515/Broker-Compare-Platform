# Broker Compare Platform - User Panel

React & Vite powered side-by-side Stock & Forex broker comparison website (Finology Select style).

## 🚀 Features
- **Dynamic Side-by-Side Comparison Engine**: Compare 2 or 3 brokers side by side with automated highlight badges (Best Overall, Best Value, Lowest Charges, Highest Rating, Fastest Execution, Best Platform, Best Support).
- **Global Live Search**: Instant auto-suggestions dropdown for stock & forex brokers, categories, and regulation tags.
- **Filterable Directory**: Filter by Stock/Forex, MT4/MT5/TradingView platforms, rating, deposit limits, and tag pills.
- **Detailed Broker Profiles**: Comprehensive view showing fee matrices, execution speeds, deposit methods, regulation proof, pros & cons, and final verdicts.
- **Educational Content & Support**: Blog guides, accordion FAQs, and instant contact inquiry form.

---

## 🛠️ Installation & Setup

1. **Navigate to the folder**:
   ```bash
   cd user-panel
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

4. **Start Development Server**:
   ```bash
   npm run dev
   ```

Runs on: `http://localhost:3000`
